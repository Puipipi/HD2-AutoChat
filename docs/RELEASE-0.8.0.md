逐战备、逐敌人类别设置自动提醒，新增飞行分类与独立冷却。

- 按 K → 设置 → 标记消息 → 战备细分设置 / 敌人体型与飞行提醒。主机、客机预设分别保存，原有仅自己可见输出保持有效。
- 新增命名预设：对当前选择的主机或客机配置保存、替换、重命名、应用、删除，或导入/导出 `.autochat` 文件。每个命名预设包含该角色的自动消息选项和逐战备/逐敌人规则；定时任务仍独立存储。预设库最多32项。
- `.autochat` 是有大小上限的 UTF-8 数据文件，严格检查字段、转义与配置值，不执行 Lua。保存采用临时文件原子替换；检测到库文件损坏时保留原文件并停用库写入，避免覆盖恢复机会。
- 战备读取参考仓库 StratagemCooldown：稳定 ID、原生名称、已加载图标材质、红蓝绿家族。面板支持搜索、分页、颜色筛选、三类一键开关，逐项设置落地标记与召唤/执行消息。
- 当前149条有效原生记录形成135个可见设置组。同名且呼叫方式一致的普通版、奖励版等共用规则，必须同时匹配两种原生名称键和呼叫类型；避免重新补给、跳跃背包等共享名称键绕过设置。显示变体数，不冒认事件具体变体 ID。未来新增同组变体可能改变代表项 ID，更新后请检查组内配置。图标只在 `can_get('material', ...)` 确认材质已加载时绘制。
- 冷却留空沿用全局每人间隔；填写秒数则按触发者 + 此规则独立计算，0 表示每次新的有效事件都提醒。500 千克炸弹与轨道凝固汽油弹幕首次升级预设 0 秒，可修改或恢复默认。总开关、会话校验和去重仍有效。
- 敌人细分为小型、中型、大型、巨型、飞行。飞行优先于体型；每类可自定义模板和冷却，小型默认关闭，普通物资仍不提示。
- 核对当前游戏数据后，目录包含 142 条可标记敌对资源（含变体、12 条飞行），排除友军。体型来自游戏内部 `UnitSize` 枚举（Small/Medium/Large/Massive），不是装甲等级或威胁等级；飞行依据组件另分。公开配置快照为 2026-09-22 / 1.007.100，不代表未来全部敌人已覆盖。
- 兼容布局下新增战备自动出现在目录，未知家族列入“任务等”。游戏二进制改变会停止读取，需要验证适配；新敌人也需更新核实后的组件目录。
