# AutoChat 0.5.0 设置与定时任务交接

日期：2026-10-08（北京时间）。接替 dsh“自动发送聊天消息模组开发”。

## 实现范围

沿用 Super Earth Armory Forge 的 1000×990 面板单位、盾形标识、黄色顶线、标题栏、斜纹标签、
双栏边框、调色板、真实字体回退链和屏幕像素命中区域。默认只有“设置”标签，未引入护甲/预设菜单。
先前的插件注册接口保留；没有插件注册时无额外标签。

左栏：自定义事件名称、类型、时间、消息，点击“添加定时任务”保存。三种模式为重复秒数、
一次倒计时、每天本机 HH:MM。右栏：最多 32 项，每页 7 项，暂停、启用、删除及完成后重启。
中文通过 Ctrl+V 粘贴，Enter 确认输入，Esc 撤销输入，Ctrl+A 清空当前框。
草稿与已添加任务隔离，编辑期间 K 不关闭面板。

任务存储在 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\AutoChat\tasks.txt`，采用数据转义，
不执行配置代码。临时文件写完后通过 MoveFileExA 原子替换。发送前先持久化消耗本次执行，
保存失败时暂缓发送并在 5 秒后重试。旧版计时器迁移失败时保留原配置，下次启动重试。

## 仍需用户实机确认

1. 进飞船后按 K，确认原生字体、盾形标识、双栏和“设置”标签。
2. 填事件名、时间、消息；中文用 Ctrl+V。确认 Enter、Esc、K 和右上 X 的行为及鼠标归还。
3. 有队友且聊天开启时，分别添加 5 秒重复、5 秒倒计时、下一分钟的每日任务；
   由队友确认收到消息。一次任务应只尝试一次，重复任务应可暂停。
4. 删除测试任务，重启游戏确认任务/暂停/完成状态持久化。

本轮没有启动游戏或发送测试消息；离线通过不能视为游戏内验收。
