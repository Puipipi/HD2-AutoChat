# AutoChat 0.7.4 — 实机标记名称与字体修复（2026-10-09）

## 实机根因

用户按顺序标记重新补给、补给小车、普通地点、非法广播站、地图任务、撤离区；随后两次标记武斗虫。采样仅使用 PROCESS_VM_READ / PROCESS_QUERY_INFORMATION，不写游戏内存，不代替用户操作游戏，不调用远程游戏函数。

1. 名称桥已验证 game.dll 的 99 字节包装函数，却错误要求间接调用目标也属于 game.dll。实际目标属于 helldivers2.exe。旧检查拦截了所有真实本地化调用，致使地图任务、空投舱和无静态目录的特殊标记一直等待名称。
2. 已保存的旧默认模板是 `队友标记了{类别}，请注意！`。已知物品和敌人的静态兜底名称虽然存在，模板未使用 `{目标}`，所以只出现类别。
3. 普通地面 kind 0 被直接过滤；地图撤离区 type 6 被当作普通地图标记。
4. 面板字号随缩放下降，长文字还会缩至6像素，灰色说明文字对比度不足。

用户随后确认能看到旧模板消息。只读检查也确认补给、补给小车、撤离区、两次武斗虫消息已存在于原生聊天历史。未发送的问题集中在名称等待和地点过滤，无需更换已验证的聊天发送路径。

## 实现和验证边界

- 本地化继续保留 DLL 包装函数、引擎指针链及调用前后校验；仅允许相同构建主 EXE 的精确入口、PE stamp、16字节签名和 committed executable MEM_IMAGE 页。错误映像、版本、地址、签名、非执行页、guard/private 页拒绝调用。
- 配置序列化升级为 v2；仅旧版配置中完全相同的旧默认模板迁移。其他自定义模板保留；用户在 v2 明确另存旧模板时也会尊重其选择。
- 地面 kind 0 通过地图开关发送“地点标记”；含坐标的 token 识别换点，保留首次基线与去重。撤离区 type 6 显示“撤离区”。
- 字号最低为视口高度的14/1080（至少9像素）；1080p为14像素、1600p为21像素。长标签按完整 UTF-8 字符省略，提升灰色文本对比度。原布局与操作方式保留。
- 测试先复现旧错误：正确 EXE 入口调用数0而预期1；旧模板没有目标名；地面点无事件；撤离区只有通用名称；旧面板字号9而预期至少14。修复后覆盖实际中文名称、空投/落地资源、任务关联、入口拒绝条件和完整读-排队-发送组合。
- 完整测试结果保存在 `work/deploy/tests-0.7.4.txt`。离线布局图由真实 Lua 绘制命令生成，使用微软雅黑模拟排版，不能证明游戏字体渲染效果。

修复包需要重启游戏加载0.7.4。上述实机数据来自修复前的0.7.3；新版原生调用、视觉和端到端发送仍待重启后实机验收。首次启用/进入房间已有标记只建基线，需重新标记。
