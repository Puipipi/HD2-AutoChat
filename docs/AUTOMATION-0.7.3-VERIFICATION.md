# AutoChat 0.7.3 — 地图任务名称验证（2026-10-09）

目标：地图任务标记使用游戏已显示的具体名称，如“获取发射代码”；同名“摧毁非法广播”的主线/支线属性读取当局配置，不按名称固定分类。

## 根因与读取路径

0.7.0–0.7.2的地图测试往HUD标记环中构造kind21记录。当前DLL的接收函数13D0A90在13D0BFC分支处理kind21，之后直接跳往返回点13D173E，不进入环插入路径。因此旧测试不能证明游戏真实地图图钉可读；仅放宽时长、本人过滤还不够。

已核对Steam build25480438的DLL，SHA256：
`2E2C3B7C2500646DADD5F2B4C6E0504DBB7E7896139F64CDDC0D1813C718F51E`。
section0 SHA256：`373FD67E02BBF277494BFA8357ACBCBC5A7E2A309B5F0B20578C7B383996658B`，RVA起点1000。
以下地址为该DLL的RVA，生产代码仍受现有版本检查限制。

| 证据 | 当前布局/行为 |
| --- | --- |
| 18B97A0生产图钉，18B3A90渲染图钉 | actor全局3326D20，数量+6C，描述符指针+110；状态从+547830开始，步长78 |
| 18B9ECE–18BA093 | 状态掩码0x4表示标记生效；+50世界XYZ，+5C地图类型，+60目标网络ID；空地点类型7、无目标7FFF |

| 5D0DE0初始化、18B4917及18B7FDD渲染 | 运行时记录位于管理器+60，步长1078；+1038为当局任务importance，由当前mission配置赋值 |

importance映射0主线、1前置、2支线、3战术；其他值保留为unknown，模板显示“任务”，不猜主/支线。
语义参考[ObjectiveImportanceType](https://raw.githubusercontent.com/shalzuth/HelldiversData/master/data/enums/ObjectiveImportanceType.json)，当前DLL的赋值与UI分组作为本版布局依据。

实现只通过既有安全内存读取器读取这些数据，不调用新增游戏函数，不写游戏任务或图钉状态。
图钉归属通过完整peer ID和玩家/化身实体映射；目标网络ID再关联任务实体，未使用坐标最近邻猜任务。
名称沿用已验证的游戏本地化入口。名称未加载会保持待解析，图钉取消后不再重试。

## 行为与验证

- 新增地图布局与任务名测试先在旧实现失败，再通过：本人/队友真实actor图钉、HUD环未启用、首次来源出现、来源换址、取消再标记、重复来源排除。
- 同一个“摧毁非法广播”名称分别测试0/1/2/3属性，名称保持一致而任务类型不同；测试“获取发射代码”和运行时名称覆盖。
- 目标身份/图钉在本地化期间变化时丢弃批次；未知importance不猜类别；四个并发任务图钉在读取预算内。
- 真实读取器→消息策略→发送替身组合覆盖本人普通图钉及“获取发射代码”任务图钉。主机/客机、单人开关、每人间隔和离队检查保留。
- 用Unicorn执行当前DLL的1255D60指令，真实解析到第75项定义（不是默认第0项）；重放18B4AEC名称选择段，默认key123及覆盖key456与Lua读法一致。诊断结果：`work/standalone/dist/diagnostics/native-map-objectives.json`。
- 完整测试256项通过，26.329秒，0失败：`work/deploy/tests-0.7.3.txt`。
- LuaJIT编译、源码片段一致性、构建门禁、ZIP CRC通过；归档规范化源码逐字节等于受测源码。
- 已检查真实Lua绘制命令生成的离线面板图：`docs/ping-preview.png`；变量分三行常显，保存提示不再盖住变量。
