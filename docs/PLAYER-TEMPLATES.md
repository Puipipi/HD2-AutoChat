# 每人间隔与玩家消息模板（0.7.6）

K → 设置 → 自动消息：**标记/召唤提醒间隔（秒）**。
统一设置一个秒数，但每名触发者分别计时。A发事件不会占用B/C的间隔；标记、召唤和执行事件使用事件冷却，冷却中的新事件直接丢弃，不排队补发。
欢迎和定时任务忽略事件冷却，也不会占用或延长事件冷却。指定触发者的扩展消息使用该玩家的间隔；未指定触发者的扩展发送计入本机玩家。0为不限制；不同电脑的模组仍各自运行。

A/B/C同时加入时，各有一条待发送欢迎，达到欢迎延迟后逐条发送，不会合成一条或互相等满最短间隔。
离队取消待发欢迎，切房重建基线并重新计时。
暂时发送失败、等待重试的事件不会阻塞其他可发送玩家；冷却中的事件不会入队。

## 可填写的变量

| 变量 | 示例 | 含义 |
| --- | --- | --- |
| `{玩家名}`、`{名字}`、`{触发者}` | `[Alice]` | 完整玩家名，三者同义 |
| `{player}`、`{player_name}`、`{name}` | `[Alice]` | 完整玩家名，英文别名 |
| `{缩写}` | A2 | 游戏HUD中的缩写及编号 |
| `{short}`、`{abbr}` | A2 | HUD缩写，英文别名 |
| `{编号}` | 2 | 队伍实际槽号1–4，不是本模组按入房顺序分配 |
| `{slot}`、`{number}` | 2 | 队伍槽号，英文别名 |
| `{类别}` | 任务建筑 | 标记与召唤消息 |
| `{category}` | 任务建筑 / OBJECTIVE BUILDING | 类别，英文别名 |
| `{目标}` | 非法广播 | 标记与召唤消息 |
| `{target}`、`{stratagem}`、`{战备}` | 重新补给 | 目标或战备名称 |
| `{动作}` | 标记 / 召唤 | 根据事件区分操作 |
| `{action}` | marked / called in | 动作，英文别名 |
| `{任务名}` | 获取发射代码 | 地图任务名称；其他标记回退目标名 |
| `{objective}`、`{task}` | 获取发射代码 | 任务名，英文别名 |
| `{任务类型}` | 主线前置任务 | 当局主线/前置/支线/战术任务属性；未知属性显示“任务”，普通标记回退类别 |
| `{objective_type}`、`{task_type}` | PRIMARY OBJECTIVE | 任务类型，英文别名 |
| `{位置}` | (123, 456, 7) | 仅标记消息，世界XYZ坐标 |
| `{position}` | (123, 456, 7) | 世界XYZ坐标，英文别名 |

这是固定变量替换，无需编写正则。中文和英文变量可以混用，未知变量原样保留。每个完整玩家名会整体加一对方括号；源名字已经整体带方括号时不会重复添加。方括号只在格式化输出时生成，不会改动原始玩家名称。`ping_sender_color` 开启时，方括号和名字一起使用该队员的游戏颜色；关闭时仍保留方括号。HUD缩写的变量值仍是 `A2`，自动标记前缀则显示为 `[A2]`。英文预设、UI语言和游戏语言相互独立；切换UI不会更改消息预设语言。
玩家名称变量用于欢迎语、定时任务和扩展发送；事件变量（类别、目标、动作、任务名、任务类型和位置）只在自动标记、召唤与任务消息中有值。
名字含百分号、花括号时按名字原样插入，不再执行第二轮替换。
资料缺失时名字/缩写为“队友”，编号为“?”；不会猜测另一人的名字或编号。名字缺失时保留“队友”回退文本，不添加方括号。
游戏聊天最多接受512个UTF-8字节；模板正文最多使用511字节，为自动添加的开头换行留出一个字节。颜色标记也计入此长度，截断会保留完整UTF-8字符并闭合颜色。

## 示例

欢迎语：

```text
欢迎 {玩家名}（{缩写}，{编号}号）加入小队！
```

新人Alice、HUD缩写A2时：`欢迎 [Alice]（A2，2号）加入小队！`。

标记消息：

```text
{玩家名}（{缩写}）标记了{目标}，位置{位置}
```

这里代入实际标记者。若模板已含缩写，可关闭“显示触发者缩写”自动前缀，避免重复。

地图任务可使用 `标记了{任务名}（{任务类型}），位置{位置}`。
同名“摧毁非法广播”的主线/支线属性来自当局任务记录；`{目标}` 也会显示游戏任务名。
升级仅迁移旧版完全相同的默认模板 `队友标记了{类别}，请注意！` 和旧版内置标记模板；其他自定义模板与括号内容保留。

召唤消息独立输入，默认 `{玩家名}召唤了{目标}`，例如 `Alice召唤了重新补给`。
也可填写 `{缩写}{动作}了{目标}`，得到 `A2召唤了重新补给`。
“战备召唤自动消息”和“战备物品标记”分别开关，仍共用该触发玩家的最短间隔。
普通地面空点与地图空白图钉不触发消息；任务和撤离区图钉保留。

定时任务：

```text
{玩家名} 提醒大家：请前往撤离点集合。
```

这里代入运行模组的本机玩家。替换在发送时进行，保存的任务和设置仍保留原模板。
当前已保存的欢迎语不会被升级自动改写，可自行粘贴以上示例。

扩展模组（需要0.7.1）：`api.send('欢迎 {玩家名}（{缩写}）', event.creator_id)`。
不传ID时使用本机信息；传入者必须仍在当前小队，且实际网络发件人仍为本机玩家。
