**238项通过，56.885秒，0失败/跳过**。输出：`work/deploy/tests-0.7.1.txt`。

新增覆盖：

- A/B/C同时加入，各发送一条带其姓名、缩写与真实编号的欢迎。
- A在等待间隔时，队列后面的B仍能发送；欢迎和标记共用对应触发者的间隔。
- decimal uint64会话ID与原生hex标记者共用同一计时身份，避免精度丢失。
- 离队清理对应间隔，切房重置；本机定时任务不占用远端玩家间隔。
- 名字中的百分号和花括号保持字面值，中文UTF8长度安全，未知变量保留。
- 实际宿主发送路径代入定时任务的本机信息；插件指定A/B独立发送，离队后拒绝。

LuaJIT编译、独立片段一致性与既有构建门禁通过。ZIP CRC通过，归档源码与当前规范化源文件逐字节相等。
